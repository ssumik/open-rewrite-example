# Spring CRUD demo (Java 17)

Minimal Spring Boot application exposing a CRUD REST API backed by an in-memory store.

Build and run tests:

```bash
mvn test
```

Run the app:

```bash
mvn spring-boot:run
# then call HTTP endpoints at http://localhost:8080/items
```

Swagger UI (after app starts):

```bash
# Open http://localhost:8080/api
```
